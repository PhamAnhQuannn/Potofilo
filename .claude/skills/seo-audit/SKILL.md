# Skill — SEO audit

## Bước
1. Duyệt các trang public.
2. Kiểm tra mỗi trang: `<title>`, meta description, OG image, Twitter card, canonical URL.
3. Kiểm tra `sitemap.xml` + `robots.txt` tồn tại + đúng.
4. Structured data JSON-LD (Person cho trang chủ, CreativeWork cho project).
5. Ảnh có alt text.
6. Ghi phát hiện + fix vào `brain/history/CHANGELOG.md`.
