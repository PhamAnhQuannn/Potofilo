# Reports — Nhật ký việc đã làm

Mỗi file ở đây là **một bản báo cáo cho một việc hoàn chỉnh**. Đọc là hiểu ngay đã làm gì, dù không rành công nghệ.

## Quy tắc
- 1 file = 1 việc trọn vẹn (1 tính năng / 1 nhiệm vụ). Không gộp nhiều việc lẻ.
- Tên file: `NNNN-<mo-ta-ngan>.md`, số tăng dần.
- Viết bằng từ đời thường (xem `.claude/rules/writing.md`).
- Viết xong không sửa; việc mới = file mới.
